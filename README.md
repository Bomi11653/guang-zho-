# 朝·广州｜符文小程序复刻原型

这是基于工作区内「视频参考.mp4」、PSD 页面、烧符动画与手机壁纸整理出的第一版可点击移动端原型。当前先复刻视频里的主链路：

`首页 → 选择方向 → 量表答题 → 指数结果 → 符文卡 → 化符过渡 → 分享页 → 保存壁纸`

## 本地运行

在 `replica` 目录执行：

```powershell
node server.mjs
```

然后打开 `http://127.0.0.1:4173`。

## 当前版本边界

- 已接入完整 36 张结果/黄符/赛博壁纸资源、4 款 loading GIF、1 款首页 GIF，以及 18 款 MP4 + 18 款 GIF 烧符动画。
- 化符阶段优先播放对应方向的 MP4，CSS 粒子/光环作为首帧和降级效果；浏览器支持范围不足时仍可完成主链路。
- 默认好运流程已切换为真实题库首批 16 题，答题计数、分值范围与视频参考的 `01 / 16` 节奏一致。
- 分享按钮目前是体验提示，保存按钮支持浏览器下载所选壁纸。
- 量表结果使用原型计算逻辑，正式上线需要接入真实题库、计分规则和内容审核。

原始 PSD、Excel、ZIP 和视频参考文件以硬链接方式集中在 `source-materials/`，不复制原始数据，方便继续做素材核对和后续迭代。
